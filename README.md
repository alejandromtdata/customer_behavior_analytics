# Customer Behavior Analytics

## Project Overview

This project analyzes customer behavior in a subscription-based digital platform using Python and exploratory data analysis techniques.

The objective is to understand how users interact with the platform, identify the factors that influence customer retention, and discover opportunities to improve business performance through data-driven insights.

---

## Business Questions

This analysis aims to answer questions such as:

- Which customers generate the highest revenue?
- Which subscription plans have the best retention?
- Does user engagement reduce churn?
- Which acquisition channels attract the most valuable customers?
- Where is revenue being lost?

---

## Dataset

The project is based on four related datasets:

| Dataset | Description |
|---------|-------------|
| **users.csv** | Customer profiles, demographics and lifecycle information |
| **sessions.csv** | User activity and engagement data |
| **transactions.csv** | Purchases, subscriptions and revenue |
| **data_dictionary.csv** | Dataset documentation and column definitions |
